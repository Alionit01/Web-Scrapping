# Web Scraping 🕷️

A collection of my web scraping practice, experiments, and projects while learning web scraping with Python.

This repository documents my learning journey from basic HTML parsing to working with dynamic websites, extracting structured data, and building practical scraping projects.

## 📚 What I'm Learning

The repository covers different tools and techniques used for web scraping and data extraction, including:

* **BeautifulSoup** — Parsing and extracting data from HTML
* **Selenium** — Automating browsers and scraping dynamic websites
* **Pandas** — Cleaning, processing, and working with scraped data
* **Camelot** — Extracting tables from PDF documents
* **Requests** — Making HTTP requests
* Data extraction and cleaning
* Working with structured data
* Building practical scraping projects

## 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/Alionit01/Web-Scrapping.git
```

Navigate into the project:

```bash
cd Web-Scrapping
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Linux/macOS:

```bash
source venv/bin/activate
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Install the required packages depending on the project you want to run.

For example:

```bash
pip install requests beautifulsoup4 selenium pandas camelot-py
```

Some projects may have additional dependencies or setup requirements.

## ⚠️ Responsible Scraping

When scraping websites, always respect the website's terms of service, `robots.txt`, rate limits, and applicable laws.

This repository is intended for **educational purposes and responsible web scraping**.
